# BreezeBlue工作台

面向 AstrBot 的 BreezeBlue 积分与语音插件。工作台左侧管理账号、积分和签到，右侧管理语音回复、语音库及音色设计。

**项目仓库：[alexicyj/astrbot_plugin_breeze_claim](https://github.com/alexicyj/astrbot_plugin_breeze_claim)**  
当前版本：**v1.2.6**。目标环境：**x86 飞牛原生安装的 AstrBot v4.29.4，Python 3.12+**。

> **开发说明：本项目均由 AI 生成，作者本人不懂任何代码及设计。** 请在使用前自行评估风险，遇到问题欢迎提交反馈。原项目及第三方资源的作者声明与许可仍予保留。

## 功能

### 积分与签到

- Cookie 导入、登录验证和解除绑定。上游接口提供资料时显示用户名、邮箱；不会向页面返回 Cookie。
- 查看可用总积分、今日可领积分和下次可领时间。当日已领取时，今日可领积分显示 **0**。
- 每日签到弹窗展示真实月份日历，点击今天的日期或签到按钮手动领取。
- 查看本插件保存的全部领取记录；更换 Cookie 保留历史，不混用不同绑定的日历标记。
- 自动签到支持时间和时区。关闭后相关设置不可编辑，下一次计划显示灰色短横杠 `-`，保存后停止定时任务；原时间保留，手动签到不受影响。

每日奖励、重置时间和是否可领取以上游接口为准。日历反映本地成功记录及接口确认的当天签到，不代表官网完整历史，也不虚构连续签到或加倍奖励。

### 语音与音色

- API Key 与音色 ID 位于语音区顶部，可单独保存连接，不覆盖其他未保存的参数。
- 语音总开关控制自动语音回复；回复策略包含智能判断和概率，语速独立于回复策略。关闭语音回复时策略不可编辑；智能判断启用时概率灰显。
- 智能模式由当前聊天模型判断使用文字或语音，并生成发音指导。关闭智能模式后按概率转换；明确要求朗读时保留原文。
- 搜索、选择音色，播放当前音色或列表音色的**语音库原始样例**。没有样例时提示，不使用其他文字替代，不额外调用收费合成。
- 通过描述设计音色，试听候选、保存并使用。自定义文字合成保留在 `/breeze test 文字` 命令与 API 中，Dashboard 不再显示底部合成试听项目。
- 高级设置依次为 API 地址、语言、字数上限、群白名单和发音风格；支持保留文字及语速设置。

只转换符合条件的 LLM 回复，不转换管理命令。超长内容、已有语音和不支持语音的平台保持原结果；转换失败保留文字。语音开关不影响积分与手动试听，自动签到开关不影响语音。

### Dashboard

插件与页面统一名称为 **BreezeBlue工作台**，使用 BreezeBlue 官方图标。桌面左右两区，手机上下排列，统一 Liquid Glass 风格及浅色、深色主题。Cookie、自动签到和高级语音设置使用折叠菜单，签到、历史与设计使用弹窗。

完成提示在 3 秒后自动隐藏，进行中任务和错误提示保留。切换音色、打开弹窗、刷新状态不会清空其他未保存的设置。没有福利、邀请、推广或主机浏览器登录页面。

## 安装

1. 停用原独立 BreezeTTS 插件，避免 `/breeze` 命令冲突和重复语音转换。其 API Key 与音色 ID 需要手动填入本插件一次。
2. 在 AstrBot WebUI 的插件页面使用仓库安装，填写：

   ```text
   https://github.com/alexicyj/astrbot_plugin_breeze_claim
   ```

   也可使用本地安装包 `astrbot_plugin_breeze_claim-v1.2.6.zip`，或把源码放入 `data/plugins/astrbot_plugin_breeze_claim/`。
3. 等待依赖安装完成并重载插件，打开「插件 → BreezeBlue工作台 → BreezeBlue工作台」。
4. 在左侧「账号认证 → 账号 Cookie」验证并保存 Cookie；按需启用自动签到、保存签到时间和时区。默认时间为 **Asia/Shanghai 08:10**。
5. 在右侧填写 API Key 和音色 ID，保存连接；按需保存语音回复策略与高级参数。

静态页面随源码和安装包提供，无需 Node.js、前端构建、Docker、独立 Web 服务或额外端口。页面使用 AstrBot v4.29.4 的鉴权、插件 Web API 和官方 bridge，不要求升级到 4.30。

「插件 → 插件设置」分为 **启用积分服务**和**语音配置**两类。积分分类没有积分总开关，仅包含自动签到、签到时间和时区；Cookie 在 Dashboard 导入。直接修改 AstrBot 官方插件设置后请重载插件。

## Cookie 与数据

在自己的浏览器登录 [BreezeBlue 官网](https://breezeblue.ai/app/home)，从开发者工具的 Application / Storage → Cookies 获取 `breeze_blue_session`，粘贴到账号 Cookie。

支持会话值、完整 `Cookie: breeze_blue_session=...` 请求头、Cookie 数组及含 `cookies` 的 storage state JSON。原 DSH 插件的 `~/.dsh/breeze-claim/cookies.json` 可直接粘贴。导入先验证登录态，失败时保留已有 Cookie；失效后需重新导入。解除绑定只移除 Cookie，不删除领取记录。

Cookie 和 API Key 是凭据，**不要提交到 GitHub 或发送到聊天中**。状态接口不会返回它们，密钥留空保存不会清除已有值。官网入口简称「打开官网」，提供地址和复制按钮；AstrBot v4.29.4 的 iframe 限制弹出新窗口，需复制地址或右键在新标签页打开，插件不会修改宿主安全限制。

内部 ID 始终为 `astrbot_plugin_breeze_claim`，数据保存于 AstrBot 的插件数据目录，默认位置：

```text
data/plugin_data/astrbot_plugin_breeze_claim/
  cookies.json   登录 Cookie
  state.json     领取记录、摘要与调度状态
  audio/         合成语音临时文件
```

尊重 AstrBot 自定义数据路径；更新插件不覆盖运行数据。设置保存于 AstrBot 插件配置文件。旧平面配置升级时备份为 `.legacy-v1.json`；旧分组配置调整时备份为 `.pre-workbench.json`。原积分服务关闭会迁移为自动签到关闭，不会因升级重新启用。旧版浏览器 `profile/` 不再使用，升级不自动删除。

**语音文件清理：每次成功合成后，删除 audio 目录中超过 1 小时的临时 WAV。不是每小时定时清理；没有新的合成时不会触发。** 语音库样例通过原始 URL 播放，不生成本地合成文件。原生环境通过 `Record.fromFileSystem` 发送 WAV；适配器若位于其他主机，须能访问音频文件。

## 管理命令

以下命令仅供 AstrBot 管理员使用，不注册 `/breezeblue` 别名：

| 命令 | 功能 |
| --- | --- |
| `/breeze status` | 查询每日积分余额与领取状态 |
| `/breeze claim` | 手动领取积分 |
| `/breeze dashboard` | 显示工作台入口 |
| `/breeze voice` | 查看语音设置 |
| `/breeze on` / `/breeze off` | 开启或关闭语音回复，智能模式同样生效 |
| `/breeze balance` | 查询 API 余额 |
| `/breeze voices 女声` | 搜索音色 |
| `/breeze test 你好` | 使用当前音色合成指定文字 |

自动签到任务每 60 秒检查一次，到点执行；失败最多尝试 3 次，间隔至少 15 分钟。无 Cookie 时不执行。尝试次数和成功状态持久化，重启不会无限重试；成功后优先按上游重置时间避免重复领取。停机期间不执行，恢复后会补执行当天已到点的任务。签到时间应设在上游每日重置之后。

## 兼容性与许可

以真实 **AstrBot v4.29.4** 的 Context、Web API、配置迁移、页面 bridge、生命周期和安装包检查进行开发验证，并覆盖 Cookie、调度、语音协议、音色设计及桌面、窄屏交互。浏览器验证使用模拟账户；未连接用户飞牛主机及真实 Cookie、API Key，线上领取、收费合成和消息平台发送仍需部署后确认。

积分使用网页接口 `GET /api/credits/summary`、`POST /api/credits/daily-claim`，不使用开发者 API Key。语音依赖 Breeze API 和样例 URL；上游协议、登录流程或音色样例变化可能影响功能。

参考 [AstrBot 插件开发规范](https://docs.astrbot.app/dev/star/plugin-new.html)。积分功能源自 [mi-tuan/dsh-breeze-claim](https://github.com/mi-tuan/dsh-breeze-claim)，语音协议和行为参考 [hangdingding/AstrBot-breezetts](https://github.com/hangdingding/AstrBot-breezetts)，语音模块为重新实现，未复制推广页面。
